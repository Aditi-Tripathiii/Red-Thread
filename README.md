# Red Thread

Red Thread is a privacy-first scam detection companion prototype. This repository now contains a responsive, dependency-free web app that demonstrates the MVP experience described in the product requirements.

## Run locally

Open `index.html` in a modern browser. No build step, account, backend, or API key is required.

## Included flows

- Protection dashboard with score, live monitoring, recent activity, and safety tips
- Manual local message/URL scan with explainable risk result
- Alerts feed with review actions
- Installed-app audit view and financial-app guidance entry points
- Privacy settings for local analysis, optional cloud analysis, monitoring, and retention
- Responsive mobile navigation and accessible labels

The current implementation is a safe front-end simulation. It does not access real notifications, SMS, email, links, banking apps, credentials, or payment systems. Real Android integrations must be added behind explicit permissions and policy review before production use.
